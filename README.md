# Library Management System

A Full Stack Library Management System built using the MERN Stack.

## Technologies Used
- React.js
- Node.js
- Express.js
- MongoDB
- JavaScript
- Bootstrap

## Features
- User Registration and Login
- User Authentication
- Dashboard
- Add and Manage Books
- Issue Book Management
- My Books Section

## Project Structure
- `backend/` – Node.js and Express.js API
- `frontend/` – React.js application

## Installation

### Backend
```bash
cd backend
npm install
npm start
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
